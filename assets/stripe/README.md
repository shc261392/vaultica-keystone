# Stripe Branding Assets

Vaultica company mark ("Chevron shield", see [`../logos/README.md`](../logos/README.md)) sized for
Stripe Dashboard branding. Stripe's requirements
([Branding your Stripe account](https://docs.stripe.com/get-started/account/branding)):

- **Format**: JPG or PNG, less than 512 KB
- **Size**: at least 128×128 px
- **Icon**: square, digital-friendly
- **Logo**: non-square; overrides the icon in some places

Every file here is PNG, 512 px or larger on its short side for sharp retina rendering, and far
under 512 KB. `pnpm build:logo` fails if any file reaches the limit.
